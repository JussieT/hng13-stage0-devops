## 🧩 Project Description
This project is part of the **HNG13 DevOps Stage 0 Challenge**, designed to demonstrate foundational DevOps skills.  
It involves deploying and configuring an **NGINX web server** on a cloud instance to host a custom webpage accessible publicly via HTTP.  
The goal is to simulate a real-world DevOps scenario — managing infrastructure, version control, and deployment automation.
